## Сравнение с сайтом-аналогом (PageSpeed Insights)
Сайт-аналог: ych.commishes.com (платформа для художников)
(Скриншот из PageSpeed Insights приложен в папке screenshots)
| Показатель  | Наш проект (Desktop, Lighthouse)        | Сайт-аналог (Mobile, PageSpeed Insights) |
|-------------|-----------------------------------------|------------------------------------------|
| LCP         | 1.2 с (горячий кэш) / 5.87 с (холодный) | 1.1 с                                    |
| INP         | 56 мс                                   | 84 мс                                    |
| CLS         | 0.01                                    | 0                                        |
| Performance | 95                                      | Высокая, зеленая зона                    |
Выводы:
1. Скорость ответа (INP): Наш проект показывает отличный INP (56 мс) против 84 мс у аналога. Интерфейс AvaBid реагирует на действия пользователя мгновенно.
2. Стабильность макета (CLS): У обоих проектов CLS близок к нулю (0.01 и 0), значит, мы правильно зарезервировали места под картинки (`width/height`), и страница не «прыгает».
3. Загрузка контента (LCP): Аналог грузит главную картинку за 1.1 с, а наш проект при холодном кэше тратит 5.87 с. Это выявило нашу главную проблему — тяжелые изображения с Supabase. Нам стоит внедрить сжатие картинок на лету (WebP), чтобы догнать аналог.

## Неисправленные проблемы и причины
1. Improve image delivery (Тяжелые картинки): Главная проблема для LCP (5.87 с). 
Причина: Исходные изображения лотов весят много (до 2 МБ). Требуется интеграция с CDN для автоматического сжатия (Supabase Image Transformation) или ручная оптимизация всех файлов перед загрузкой.
2. Use efficient cache lifetimes (Кэширование): Браузер каждый раз скачивает картинки из Supabase заново. 
Причина: Требуется настройка заголовков `Cache-Control` на стороне сервера.
3. Render-blocking requests (Google Fonts): Шрифты загружаются со стороннего сервера и блокируют рендеринг (экономия 762 мс). 
Причина: Исправление требует скачивания шрифтов и настройки локального хостинга.
